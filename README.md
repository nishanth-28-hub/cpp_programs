# C++ Programming Practice

## 📌 About This Repository

This repository contains a collection of **C++ programs** created to learn and practice fundamental programming and Object-Oriented Programming (OOP) concepts.

The programs are written in a simple and beginner-friendly manner, with user input wherever required. The main focus is on understanding the concepts through practical implementation.

## 📚 Concepts Covered

- Arrays
- Two-Dimensional Arrays
- Pointers
- Pointers with Arrays
- Classes and Objects
- Arrays of Objects
- Structures
- Unions
- Enumerations (`enum`)
- Constructors
- Default Constructors
- Parameterized Constructors
- Function Overloading
- Inheritance
- Protected Access Specifier
- Dynamic Memory Allocation
- Pass by Value
- Matrix Operations
- Object-Oriented Programming (OOP)

## 🎯 Purpose

The purpose of this repository is to strengthen my understanding of **C++ programming fundamentals and OOP concepts** through hands-on practice.

These programs help in developing programming logic and understanding important concepts such as **memory management, data structures, classes, objects, constructors, inheritance, and polymorphism**.

## 🚀 Learning Outcome

Through these programs, I have gained practical experience with the basic features of C++ and developed a stronger foundation in programming and Object-Oriented Programming.

This repository represents my **C++ learning and practice journey**.
